## Open

<a id="q-voice-shape"></a>
### q-voice-shape · `VOICE_COMMAND` body

- **Known:** error frames are generated by the robot ([q-voice-error](#q-voice-error)).
  `VOICE_COMMAND` frames come from the voice server and are passed through unchanged; the SDK,
  smoke.py and [api.md#voice-events](../docs/reference/api.md#voice-events) use
  `{type = "VOICE_COMMAND", data = {keyword = "..."}}` and `data.status == "unavailable"`. The
  `e.keyword` in an engine comment is stale [fw: head_esp32/components/game_engine/src/bindings/bind_voice.c:17].
- **Safe way:** check every level before reading it:

```lua
function on_voice_event(e)
  if type(e) ~= "table" then return end                -- raw string past the decoder caps
  if e.type == "VOICE_COMMAND" and type(e.data) == "table" then
    local kw = e.data.keyword
    if type(kw) == "string" then handle_keyword(kw)
    elseif e.data.status == "unavailable" then voice_ok = false end
  elseif e.type == "error" and e.code ~= "busy" then   -- busy: the old list stays
    voice_ok = false                                   -- keep buttons working
  end
end
```

<a id="q-a2a-swap"></a>
### q-a2a-swap · keyword swap in talk-flow

- **Known:** in a talk-flow (A2A) session the keyword body is forwarded to the conversation
  (`CONV_NotifyGameKeywords`) and the offline voice session stays idle
  [fw: back_esp32/main/src/application/game_voice/game_voice.cpp:578-583]. Whether a second list
  replaces the first there is not settled.
- **Safe way:** send one list per talk-flow session, or `Voice.stop()` then `set_keywords`, as offline.

<a id="q-publish-names"></a>
### q-publish-names · file names at publish time

- **Known (robot):** the SD card is FAT with code page 437, OEM API encoding, long names
  [fw: head_esp32/sdkconfig:1902,1923-1925]: names are case-insensitive and non-ASCII bytes do not
  round-trip. Engine path rules: [api.md#conventions](../docs/reference/api.md#conventions).
  The rules of the Pika platform's publishing step are not documented.
- **Safe way:** lowercase ASCII letters, digits, `_` and `-`; one `.` before the extension; no
  spaces; never two names that differ only in case.

## Closed

<a id="q-keyword-swap"></a>
### q-keyword-swap · `set_keywords` while listening (offline) ✅

A second `set_keywords` while connecting or listening is refused with an `error`/`busy` event and
the old list stays. To swap: `Voice.stop()`, then `set_keywords(new)`; the robot reconnects
[fw: back_esp32/main/src/application/game_voice/game_voice.cpp:537-604]. See [api.md#voice](../docs/reference/api.md#voice).

<a id="q-voice-error"></a>
### q-voice-error · error frames ✅

Error frames are generated by the robot as `{type = "error", code, message}` with one of nine
codes; `connect_failed`, `connect_timeout`, `ws_disconnected`, `ws_error` end the game
[fw: back_esp32/main/src/application/game_voice/game_voice.cpp:157-174, 418-431]. Table:
[api.md#voice-events](../docs/reference/api.md#voice-events).

Also settled earlier (do not reopen): sprites may be created in `game_start` · `dt_ms` is nominal ·
`set_font` returns nothing on success · `on_home` truthy keeps the game · sounds live in
`audio.sounds.<alias>.path` · `Voice.is_available()` is false during `game_start` · `s.json` is
issued by the Pika platform, never by Pika Studio or by hand.
